# Music Library App — Phase 1 handoff

This package is the implementation brief for Phase 1 of the app.

## Read these files in order

1. `PHASE-1-IMPLEMENTATION.md` — product scope, screens, behaviours and acceptance checks.
2. `AI-STUDIO-START-PROMPT.md` — paste this into Google AI Studio after attaching the package files.
3. `design-skill/APPLE-DESIGN-SKILL.md` — the supplied Apple Design skill. Apply it to interaction craft, not as permission to invent new product features.
4. `flow-boards/` — Figma flow-board exports. These are the primary visual and navigation references.

## Important source-of-truth rules

- The flow-board exports show the user's intended app and its Phase 1 flows. Follow them first.
- The written implementation brief resolves the explicitly corrected details, including persistent Search access and the live multi-select count.
- Do not use generic Shazam screenshots or unrelated generated concepts to override the user's own flow boards.
- If a detail is genuinely absent from both the boards and this brief, do not invent a feature. Use the smallest sensible implementation only when required to make an explicitly requested action work; otherwise leave it out and ask one focused question.

## Suggested upload workflow

Unzip this package. Attach the Markdown files, the Apple Design skill and the six flow-board images to Google AI Studio. If the interface does not accept a ZIP, upload the extracted files individually. Keep the folder names and filenames intact so the references remain easy to identify.

Build only Phase 1. Phase 2 is intentionally out of scope.
