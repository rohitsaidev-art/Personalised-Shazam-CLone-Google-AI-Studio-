# Music App — Design Engineering Pack

A focused workflow pack for the existing React music-identification/library PWA.

## Included
- `SKILL_SELECTION.md`: selected Emil Kowalski and Vercel skills, why they matter, and which to skip.
- `DESIGN_ENGINEERING_WORKFLOW.md`: the staged audit → plan → implementation → verification process.
- `MASTER_REFINEMENT_PROMPT.md`: the prompt to use after the current AI Studio audit-only pass returns.
- `DESIGN.md`: initial project-specific quality rules based on decisions already made in this project.
- `SOURCE_LINKS.md`: original upstream skill and guideline sources.

## Important distinction
This package is a curated orchestration/reference pack. It does not pretend to contain the complete original source files for every upstream skill. The original skills are maintained in their respective repositories and should be installed/imported by an environment that supports Agent Skills. If AI Studio Build cannot install Agent Skills natively, attach this pack and ask it to follow the workflows and linked guidance explicitly.

Do not apply the master prompt until the current audit-only report is available. First compare that report with the actual rendered app and screenshots.
